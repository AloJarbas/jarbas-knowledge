# Secondary study stream traffic-light card

When the main study lane is proof-heavy or otherwise cognitively expensive, the second stream should not run on hope.
It should run on evidence.

This card is a simple load-control rule:

- **green**: keep one secondary stream active
- **yellow**: shrink it to preview mode
- **red**: pause it and repair the main lane

## What the colors mean

### Green

Keep the secondary stream active when the main lane is still producing clean output.

Signs:

- finished proofs or solved problems are appearing steadily,
- delayed rewrites from memory still work,
- error tags are not multiplying,
- definitions are starting to feel reusable instead of freshly memorized every session.

What to do:

- keep one secondary stream alive,
- do not expand two secondary streams at once,
- keep most effort on the main lane anyway.

### Yellow

Yellow means the base is still alive, but it is wobbling.

Signs:

- more fragments than finished work,
- delayed recall collapses,
- the same notation or logic errors keep returning,
- secondary reading is eating the time that should have gone into exercises or rewrites.

What to do:

- shrink the secondary stream to **preview mode**,
- reduce it to one or two light sessions per week,
- focus on vocabulary, orientation, and worked examples,
- stop pretending that exposure equals mastery.

### Red

Red means the main lane is no longer compounding.

Signs:

- the journal is turning into copied reading notes,
- no-notes rewrites mostly fail,
- the same proof or setup errors survive for several weeks,
- the second stream is clearly stealing repair time from the first.

What to do:

- pause the secondary stream,
- repair the base,
- return to short proofs, definitions, rewrites from memory, and a narrower workload.

Pausing is not quitting.
It is refusing to bury a weak foundation under more content.

## Preview mode, defined

A lot of study plans fail because they do not distinguish between **active study** and **preview mode**.

Preview mode is lighter by design:

- one short lecture or chapter,
- one worked example audit,
- a tiny problem set,
- no pressure to finish the whole track.

That is often the right state for a useful but non-primary subject.

## Weekly decision rule

Ask these four questions once per week:

1. What is the actual main lane this week?
2. What finished output proves it is alive?
3. Is the secondary stream helping the main lane or taxing it?
4. If I keep this load for one more week, what breaks first?

If the honest answer to the last question is "the main lane," then the secondary stream should shrink or pause now, not later.

## Adversarial check

A fair objection is that a second stream can keep motivation alive.

True.

But that only justifies a **light** second stream.
It does not justify running two full-strength lanes while the core work is deteriorating.

Motivation helps.
False evidence of progress does not.
