# From raw research pass to public note

A raw research pass is not the public artifact.
It is the quarry.

The job is to extract the smallest stable thing worth keeping.

## The rule

Do not publish the whole session by default.
Publish the **one claim, comparison, checklist, or next experiment** that survived the session.

## A simple extraction sequence

1. **Name the surviving idea**
   - What is the one thing that still looks true after source review and adversarial checking?

2. **Set the boundary**
   - What is this note not trying to do?
   - What neighboring topic is being left for later?

3. **Pick the artifact shape**
   - decision card
   - comparison note
   - experiment brief
   - checklist

4. **Keep provenance lightweight but visible**
   - source basis
   - why those sources were trusted
   - what got rejected or excluded

5. **Leave the residue in a dated research log**
   - false starts, dense source triage, and local scratch work can stay there

## Minimum provenance block

A public note does not need a giant bibliography every time.
It does need enough lineage that later-you can trust it.

Minimum viable provenance:

- 2-5 accepted sources
- one line on why they were good enough
- one rejected or excluded source class when that matters

## Good scope boundary test

If the note is trying to be:

- a decision rule,
- a literature review,
- a tutorial,
- and a project log

all at once, split it.

## Good public artifact shapes

### Decision card
Use when the output is mainly a choice rule.

### Comparison note
Use when the output is mainly a tradeoff map.

### Experiment brief
Use when the output is mainly the next test worth running.

### Checklist
Use when the output is mainly a repeatable review habit.

## What not to do

- do not dump raw highlights and call it knowledge
- do not remove provenance until the note becomes unsupported taste
- do not keep the claim so broad that nothing can link to it cleanly
- do not fragment one idea into five tiny notes that only make sense together

## Compact test before publishing

Ask:

- what is the claim?
- where does it apply?
- where does it stop?
- what sources earned trust?
- what smaller artifact shape is this, exactly?

If those answers are visible, the note is probably ready.
